# Casa Comtal · Obrador Café

Website for Casa Comtal, a bakery and café at Carrer Comtal 21, 08002 Barcelona.

Static site: `index.html` plus photos in `img/`. No build step. Open the file in a browser, or host the folder anywhere (GitHub Pages, Netlify, etc.).

- Spanish by default, with an EN toggle; visitors whose browser isn't set to Spanish or Catalan see English first.
- Menu prices are copied from the in-store board. Update them in the `#carta` section of `index.html`.
- Only the closing time (20:30) is listed; the page sends visitors to Google Maps for full opening hours.
